# Black Hole Calculator

A simple and high-precision Python CLI tool to calculate key physical properties of a non-rotating (Schwarzschild) black hole based on its event horizon radius.

## Features
- **Mass Calculation:** Finds the exact mass in kilograms without scientific notation truncation.
- **Evaporation Time:** Calculates the complete Hawking radiation lifetime in seconds and years.
- **Average Density:** Computes the mean density inside the event horizon.
- **Arbitrary Precision:** Uses Python's built-in `decimal` module to handle extreme astronomical numbers accurately.
